MovRec:
A lightweight, responsive web application built with vanilla HTML, CSS, and JavaScript that interacts with the **TMDB (The Movie Database) API** to discover popular movies, search titles, view rich details (cast, ratings, genres, release year), and link directly to official YouTube trailers.

Features
**Popular Movies Feed:** Loads top movies instantly upon loading.
**Search Engine:** Query movies in real-time with 'Enter' key support.
**Interactive Modals:** Detailed view featuring poster artwork, release dates, synopsis, top cast list, ratings, and YouTube trailer links.

Simply clone the repository and open `index.html` in any web browser, or host it live instantly via GitHub Pages.
